# Data Analyst Assistant – RAG + LLM + Vector Store
An AI-powered Data Analyst Assistant that ingests data from a website, converts it into a searchable vector database, and enables natural language conversations with the data using Retrieval-Augmented Generation (RAG) and Large Language Models (LLMs).

This project demonstrates how to combine web scraping, document embedding, vector search, and conversational AI into an interactive assistant for data analysis.

📌 Features
  - Web Data Extraction – Automatically scrapes all links from a website.
  - Smart Document Tagging – Categorizes pages by content type.
  - Text Chunking & Embedding – Stores text chunks in a vector database (ChromaDB).
  - RAG-based Chatbot – Answers questions using relevant document context.
  - 2D Embedding Visualization – Uses t-SNE for intuitive data mapping.
  - Interactive Chat Interface – Powered by Gradio inside Jupyter.
